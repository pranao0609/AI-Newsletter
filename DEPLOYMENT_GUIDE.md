# Deployment Guide to Render (Free Tier)

This guide walks you through deploying your AI News Aggregator to Render using the free tier for both the web service and the database.

## Prerequisites
- A [Render.com](https://render.com) account.
- A GitHub/GitLab account where this repository is hosted.
- An account on [cron-job.org](https://cron-job.org/) (or similar) to trigger the daily pipeline.

## Step 1: Push Code to GitHub
Ensure all your local changes are committed and pushed to your remote repository.
```bash
git add .
git commit -m "Configure free tier deployment for Render"
git push origin main
```

## Step 2: Create Blueprint on Render
1.  Log in to your [Render Dashboard](https://dashboard.render.com/).
2.  Click **New +** and select **Blueprint**.
3.  Connect your GitHub repository (`ai-news-aggregator`).
4.  Give your blueprint a name (e.g., `ai-news-aggregator`).
5.  **Environment Variables**: Render will detect the `render.yaml` file and ask you to fill in the values for:
    *   `GROQ_API_KEY`: Paste your key starting with `gsk_...`
    *   `MY_EMAIL`: Your email address (e.g., `pranaoadhau@gmail.com`)
    *   `APP_PASSWORD`: Your Gmail App Password (NOT your login password).
6.  Click **Apply**.
    *   Render will now create a **Database** (PostgreSQL) and a **Web Service**.
    *   Wait for the deployment to finish (it might take a few minutes).

## Step 3: Get Your Web Service and CRON_SECRET
1.  Once deployed, go to the **Dashboard**.
2.  Click on your new **Web Service** (it might be named `ai-news-aggregator`).
3.  Copy the **URL** (e.g., `https://ai-news-aggregator.onrender.com`).
4.  Go to the **Environment** tab on the left sidebar.
5.  Find the `CRON_SECRET` variable. **Copy its value**. (It was auto-generated by Render).

## Step 4: Schedule the Daily Job (Free)
Since we are using the Free Web Service, we need an external tool to "wake up" the app and run the job.

1.  Go to [cron-job.org](https://cron-job.org/) and sign up.
2.  Click **Create Cronjob**.
3.  **Title**: AI News Daily Digest
4.  **URL**: `https://<YOUR-RENDER-URL>/run-pipeline`
    *   *Example*: `https://ai-news-aggregator.onrender.com/run-pipeline`
5.  **Execution Schedule**: Select "Every day" at your preferred time (e.g., 09:00).
6.  **Advanced settings** (Required for security):
    *   **HTTP Method**: Change `GET` to `POST`.
    *   **Headers**: Add the following header:
        *   Key: `Authorization`
        *   Value: `Bearer <YOUR_CRON_SECRET>`
7.  Click **Create Cronjob**.

## Done!
Your application is now deployed!
- The app sleeps when not in use (saving free hours).
- The external cron job wakes it up once a day.
- The web service processes the news and sends the email.
- The logs can be viewed in the Render Dashboard under **Logs**.
